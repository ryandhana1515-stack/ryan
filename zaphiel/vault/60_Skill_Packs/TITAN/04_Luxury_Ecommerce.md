# Luxury, fashion and product experiences

**TITAN decides the story** for cinematic products (Ryan, 2026-10-12). The films come from TITAN 3D Studio
(Kling/Higgsfield). The site is built with the site kit on Vercel.

## Story picks (start here, adapt to the real product)
| Product | Hero effect | Scenes |
|---|---|---|
| Watch | Splits into its visible parts and reassembles | reveal → split → macro between layers → new angle → reassemble → light sweep + CTA |
| Clothing / tailoring | The garment forms itself | fabric ribbons → garment builds → worn → collection walks → stitching macro → CTA |
| Car | Panels lift and settle; 360 | silk slides off → light blades → panels lift → 360 → launch on a wet road → badge macro |
| Motorbike | Exploded parts snap together | parts float → snap together → 360 → engine fires, launch → engine macro → rider at dawn |
| Drinks (can, bottle, cocktail) | Ingredients and pour | ingredients float in → the pour/splash freezes → the can/bottle assembles → condensation macro → CTA |
| Jewellery | Molten gold, the stone set | pour → cast → stone set throws fire → turn → claw macro → on a hand |
| Perfume / skincare | Glass and a liquid column | cap and pump lift → liquid column → light through glass → texture macro |

Every part shown must exist in the real product (doctrine §8). Generated product imagery is labelled
"Illustrative" until the client supplies photography. Never imply a render is a real photograph.

## Design
Editorial layout, huge display type, one idea per screen, material close-ups, a 3–5 colour material palette (the
doctrine's Material Director, §25), fast responsive galleries, an elegant path to buy or enquire. No discount strips,
countdowns or pop-ups on luxury sites.

## Stores
- **Client's Shopify** (their subscription) or a custom checkout (Stripe/HitPay) through ATLAS.
- **Clothing:** collections, size guide, product structured data (titan-seo), wishlist/cart.
- **Catalogue feeds** for Meta/TikTok/Google shopping: verify each platform's current requirements on the project.
- Prices, stock and offers come only from the client.
- Never use Ryan's Bio Elixirs Shopify store for client work.
