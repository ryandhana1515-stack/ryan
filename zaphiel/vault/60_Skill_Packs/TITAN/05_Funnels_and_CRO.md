# High-converting pages and funnels

## Every page has
A clear audience · one offer · visual hierarchy · **one primary CTA** (repeated, sticky on phones) · trust signals
(real only) · a mobile-first layout · readable copy · **a measurable conversion event**.

## Conversion paths
WhatsApp enquiry (click-to-chat with a prefilled message) · lead form (qualifying fields + PDPA consent) · booking ·
quote request · purchase · call.

## Funnel types (pick one per goal)
| Funnel | Use when | Pages |
|---|---|---|
| WhatsApp-first | Local services in Singapore (default) | landing → WhatsApp with a prefilled message → John |
| Lead magnet | B2B, considered purchases | landing → form → thank-you + download → nurture |
| Booking | Clinics, salons, consultations | landing → calendar → confirmation → reminder |
| Quiz | Many options (skincare, renovation) | quiz → result page with a recommendation → CTA |
| VSL (video sales letter) | High-ticket offers | video page → CTA below the video → booking |
| Webinar | Education, coaching | registration → reminder → replay → offer |
| Product launch / tripwire / upsell | DTC, e-commerce | launch page → checkout → one-click upsell → thank-you |

## Tracking pack (every site)
- **Capture on landing:** `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, `gclid`, `fbclid`,
  `ttclid`. Keep them in first-party storage for the session and send them with every lead.
- **Events:** `form_submit`, `whatsapp_click`, `booking_complete`, `purchase` (Marketing names the pixel/CAPI
  events).
- **Into the CRM through ATLAS:** the Fusion EDG lead attribution table already stores UTM + gclid + fbclid
  (migration 026); `ttclid` needs a column (ask ATLAS).
- **Speed-to-lead:** every lead reaches John or the sales team at once, with an owner and a next action (ATLAS).

## AI assistant on the site (optional)
Answers only from the client's approved knowledge; qualifies and books; hands off to a human or WhatsApp; says
clearly that it is an AI.

## Optimisation
- A/B plan: one variable at a time (headline, offer, CTA, hero), enough traffic before deciding.
- Monthly review with the Marketing Director (analytics, heatmaps if the client has them).
- **Live test before launch:** real test submissions end to end. No beautiful but dead buttons.
