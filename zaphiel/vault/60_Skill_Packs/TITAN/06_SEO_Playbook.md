# SEO, local SEO and AI-search readiness (titan-seo)

## Technical
Crawlable and indexable · one canonical URL per page · XML sitemap · robots.txt · 301 map on every migration ·
hreflang for multi-country/language · structured data in JSON-LD where the content qualifies (Organization,
LocalBusiness, MedicalClinic/Physician, Product, FAQPage, Article, BreadcrumbList, real-estate listings) · unique
title (≈50–60 characters) and meta description (≈150–160) per page · one H1 and ordered headings · alt text ·
internal links · Core Web Vitals good on mobile · mobile usability.

**Cinematic sites:** keep all copy as real HTML text (not baked into films), give each film chapter a heading,
make sure the page reads fully without JavaScript, and lazy-load films so they don't hurt LCP.

## Local SEO (Singapore first)
Google Business Profile guidance (the client owns and verifies it) · the same name/address/phone everywhere · local
pages only where the client truly serves · a reviews plan with real customers (never incentivised or fake reviews).

## Content
- Keyword/intent research with free tools first: Search Console, Google autocomplete, People Also Ask, Keyword
  Planner where available.
- Useful, factual, human-reviewed content.
- Programmatic pages (e.g. property/location) only with genuinely unique, useful content per page.
- No mass low-value AI pages: search engines penalise scaled low-quality content.

## AI-search readiness
Clear factual answers near the top of pages, FAQs, consistent entity facts (name, address, services, people),
authoritative sources cited, fast crawlable pages. `llms.txt` and similar conventions: **experimental**, optional.

## Measurement (free)
Google Search Console + GA4 + Bing Webmaster Tools, owned by the client, who grants access. Monthly report: impressions,
clicks, CTR, positions, indexed pages, Core Web Vitals.

## Never
Guarantee rankings, traffic or AI citations. Mark up fake reviews/ratings. Copy competitors' content.
