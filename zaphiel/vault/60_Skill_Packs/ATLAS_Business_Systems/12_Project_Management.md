## Card format
_Fields below complete Ryan's card format (SIGNALS • ASK • CORE OBJECTS • KEY EVENTS • WORKFLOWS • KPIs • KEEP/BUY/BUILD • CONTROLS & RISKS). They are Zaphiel's additions, not Ryan's words; where Ryan's text already covers a field it is referenced, not repeated._

**SIGNALS** — Deliveries take weeks with many steps and people; milestones slip; "who is doing what?".

**ASK** (1–3 at a time, plain words, only what is still unknown)
- "Which tool, if any, do you use to track projects today?"
- "What are the usual stages of a project, from start to handover?"
- "How do you know a project is behind?"

**CORE OBJECTS** — project · phase · task · dependency · milestone · timesheet (only if billed by time).

**KEY EVENTS** — `project.created` · `milestone.due` · `task.overdue` · `project.completed`

**WORKFLOWS** — Won deal → project from a template → tasks with owners and dates → milestone updates → customer update → handover.

**KPIs** — Milestones on time (*Are we delivering on schedule?*) · overdue tasks per owner (*Who is overloaded?*).

**KEEP/BUY/BUILD** — See Ryan's decision list. Connect the existing tool before replacing it.

**CONTROLS & RISKS** — Project data linked to the customer record; access by role.
