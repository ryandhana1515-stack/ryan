# Website design standard — the S$10,000 bar

Ryan's rule (2026-09-25): **no generic AI websites.** Every mock-up must look as though a brand
strategist, UX designer, UI designer, copywriter, art director, motion designer and front-end
engineer worked together. The customer must think "they understand my company", not "another AI
template".

## Rejected on sight
- Dark navy background with a purple/blue gradient
- Random glowing balls or blurred colour blobs
- Generic frosted-glass cards
- Random or irrelevant stock photography
- One huge generic headline that says nothing specific
- Three identical feature boxes in a row
- Generic SaaS landing-page layout
- The same font pairing on every website

## Before designing, decide
| Decision | Rule |
|---|---|
| **Brand personality** | Pick two or three: luxury, clinical, professional, friendly, technical, minimal, premium, warm, corporate, editorial, modern. Must fit *this* business. |
| **Typography** | A deliberate pairing for this brand. Never the same pairing twice in a row. |
| **Layout** | Intentional hierarchy: one message and one action per section. No repetitive AI section patterns. |
| **Imagery** | The actual business only. When custom visuals would materially help, use the creative pipeline (Higgsfield / Kling) — never a stock photo that could belong to anyone. |
| **Motion** | Only where it improves the experience: scroll interactions, micro-interactions, transitions, product/service reveals, data visualisation, before/after where appropriate, a premium hero animation. Never overload. |
| **Palette** | From the brand or the business. Never a default gradient. |

## Two modes
- **SME** — professional services, beauty, property, technology, consulting, retail, education,
  home services, B2B, local businesses, F&B, logistics. Understand the business, audience, offer,
  brand, competitors, desired action, existing website and assets, style preference and market
  positioning before designing.
- **Medical / Doctor** — doctors, clinics, specialists, dental, aesthetic practices, medical
  groups, healthcare providers. Needs doctor profiles, credentials, specialties,
  treatments/services, clinic locations, appointments, contact, patient information, FAQs,
  educational content, privacy, an information-only medical disclaimer and a jurisdiction-specific
  advertising/compliance review. **Never fabricate** qualifications, medical claims, success rates,
  testimonials, certifications or treatment outcomes. Missing medical facts are marked
  **[VERIFY WITH CLINIC]** and the customer verifies them before anything is shown to patients.

## The mock-up pipeline
Client discovery → industry analysis → brand direction → website architecture → copy direction →
visual direction → Lovable build brief → mock-up → **quality review** → human review (Ryan) →
customer preview.

## QA before any customer sees a site
Desktop and mobile responsiveness · navigation · spacing · typography · contrast · accessibility
basics · broken links · forms · CTAs · image quality and relevance · copy accuracy · loading and
performance · SEO fundamentals · metadata · contact information · brand consistency · visual
hierarchy · animations · claims · placeholder content. Medical sites add a medical-content
verification pass.
