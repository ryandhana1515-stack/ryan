# cinematic-website

The "cinematic-website agent" that Ryan's agent files name (for example [[10_Agents/16_Fusion_Property_SG]] §1 and
§14) is not a separate agent file. It is the cinematic website capability of the Website Builder chain:

- **Doctrine:** [[Knowledge/Full Master Cinematic Website Agent 2026]]. Its section 10 is the PROPERTY spatial
  journey.
- **How to get the wow:** [[Knowledge/Wow website playbook]]. It covers the scene film, the look bible, the chained
  scenes and the property recipes.
- **The build:** the site kit (`ceo-brain/site-kit/`, README) and the Website Build Worker routine
  (`ceo-brain/agents/website-build-worker/ROUTINE.md`). Mock-ups are hosted on Vercel, with Higgsfield as the
  fallback.
- **Research first:** [[10_Agents/05a_Website_Intelligence]].

"The cinematic-website agent's PROPERTY module" means the property journey in these three places.
