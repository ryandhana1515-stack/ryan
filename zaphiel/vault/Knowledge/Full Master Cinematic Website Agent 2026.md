# Full Master Cinematic Website Agent 2026 (Ryan, verbatim)

> Ryan's governing document for every Fusion Tech AI website agent (2026-09-29). Copied word for word from the PDF in
> `_sources/`; only the page headers were removed. Section 26 says: feed this to every website agent.

**FUSION TECH AI — FULL MASTER CINEMATIC WEBSITE AGENT 2026** · HIGGSFIELD × LOVABLE × CLAUDE × 3D
Bidirectional scroll storytelling · Exploded products · 360° · Parallax · Pinned scenes · Conversion

## 1. Core doctrine
This is the governing knowledge document for Fusion Tech AI website agents. Build interactive conversion stories, not stacked
template sections.
- Scroll down progresses the story; scroll up reverses it.
- Core animation state comes from scroll progress, not one-way timers.
- Every effect must explain, demonstrate, dramatize or convert.
- Use real references for factual products, properties and anatomy.
- Mobile/reduced-motion versions preserve the story with lighter media.

## 2. Agent pipeline
John/Sales → Website Intelligence → Creative Director → 3D/Asset Director → Higgsfield Director → Lovable Website Creator →
QA/Conversion → John.
- Website Intelligence owns facts/research.
- Creative owns 3 directions + story.
- Asset Director selects animation engine.
- Higgsfield owns generated cinematic source media.
- Lovable/code owns the actual scroll interaction and integrations.
- QA tests reverse behavior, conversion, mobile, factual integrity and performance.

## 3. Animation engine selection
- REAL_TIME_3D: accurate 3D model exists; scroll drives camera/object/parts.
- SCROLL_SCRUB_VIDEO: cinematic sequence maps scroll progress to media time.
- IMAGE_SEQUENCE: precise frame-by-frame control.
- CSS_SVG_DOM: type, diagrams, masks, gradients, callouts, lightweight depth.
- STATIC_FALLBACK: reduced motion, weak device, bandwidth or mobile constraint.
**ENGINE ROUTER**
For every scene choose one engine and explain why. Never use WebGL merely to look expensive. Never create an exploded
engineering/product view without accurate geometry/reference.

## 5. Bidirectional scroll specification
**REVERSIBLE TIMELINE**
Implement each cinematic chapter as a deterministic timeline tied to normalized scroll progress p ∈ [0,1]. Down increases p; up
decreases p. At any p, state is reproducible.
Define keyframes p=0,.25,.5,.75,1 for camera; object position/rotation/scale; part separation; opacity; blur; text; depth layers;
media time/frame; CTA.
Avoid one-way core animations. Do not scroll-jack. Sticky/pinned scenes only when useful.
Reduced motion: static chapter states + normal document flow.
Mobile: simplify layers and use pre-rendered media when real-time 3D is expensive.

## 7. Parallax depth
- Atmosphere/gradient light: fixed or slow.
- Environment/background: slowest.
- Hero object: moderate.
- Foreground detail: faster but restrained.
- Typography/UI: stable enough to read.
- Reverse restores every layer exactly.
- Avoid looping motion that fights user scroll.

## 8. WATCH — exploded 360°
Reveal → macro dial → controlled 360/orbit → accurate component explosion → callouts → reassembly + purchase CTA. Reverse
reassembly → explosion → orbit → reveal.
**INDUSTRY SCROLL MODULE**
Use supplied accurate watch model/reference. p=0 assembled hero; .2 macro; .4 rotation; .55 separation begins; .75 maximum
accurate exploded state; .88 reassembly; 1 assembled alternate hero + CTA. Reverse interpolates all parts/camera states backward.
Never invent parts. DOM/SVG labels. Mobile: pre-rendered reversible sequence.

## 9. CAR — orbit / exploded systems / cabin
Silhouette → 360 exterior → optional accurate body/wheel/interior separation → cabin/feature → reassembly → test-drive CTA.
Reverse returns cabin → exploded → orbit → silhouette.
**INDUSTRY SCROLL MODULE**
Use accurate vehicle model/reference. Never invent mechanical components/specs. Scroll drives camera/object transforms. Verified
feature labels in DOM. If geometry is incomplete, use cinematic video rather than fake internals. Mobile: simplified orbit or
pre-rendered sequence.

## 10. PROPERTY — spatial journey
Exterior/aerial → approach → entrance → interior → real floor plan → neighbourhood/map → agent → viewing/valuation CTA.
Reverse exits the property in order.
**INDUSTRY SCROLL MODULE**
Use real property assets. True 3D if accurate architecture exists; otherwise coherent Higgsfield/rendered shots scrubbed by
scroll. Never fabricate rooms, views, facilities or dimensions. Verify map/project facts. Create transition-compatible start/end
frames.

## 11. CLINIC / MEDICAL
Human/doctor → concern/treatment area → educational anatomy → clinician-reviewed mechanism → outward return →
suitability/safety → consultation. Reverse anatomy outward to patient view.
**INDUSTRY SCROLL MODULE**
Use approved anatomical references and clinician-reviewed copy. Do not invent injection points, dosage, needle depth, protocols,
outcomes or anatomical claims. Generated visuals are illustrative unless medically validated. Non-gory. HTML labels. Reduced
motion uses static diagrams.

## 12. BEAUTY / AESTHETICS
Natural macro → technique/layer → genuine transformation → specialist/process → booking. Surface-to-layer-to-surface reverses.
**INDUSTRY SCROLL MODULE**
Use genuine consented transformation material. Avoid unrealistic retouching. Medical/aesthetic anatomy follows clinician-review
rules. Keep booking reachable.

## 13. JEWELLERY / LUXURY PRODUCT
Material reveal → 360 → macro craft → optional accurate exploded/construction view → lifestyle → purchase. Reverse restores

**INDUSTRY SCROLL MODULE**

on mobile if necessary.

## 14. ELECTRONICS / DEVICE
Hero → 360 → accurate internal layers → verified feature callouts → product/UI → reassembly → buy/demo.
**INDUSTRY SCROLL MODULE**
Use real CAD/3D/reference. Never invent chips, sensors, battery or internals. Scroll drives separation/camera. Reverse reassembles

## 15. FURNITURE / INTERIOR
Room reveal → hero product/material → real joinery/construction → configuration/transformation → quote/shop.
**INDUSTRY SCROLL MODULE**

## 16. INDUSTRIAL / MARINE / ENGINEERING
Facility/machine → process → accurate machine visualization → certifications/capacity → case → RFQ.
**INDUSTRY SCROLL MODULE**

## 17. F&B / HOSPITALITY

Prefer cinematic scrubbed media over heavy 3D. Down-scroll advances craft; up-scroll reverses visual sequence. Keep menus/booking

Customer problem → life-stage/planning journey → transparent calculator/diagram → advisor authority → proof/process →

Outcome → product/workflow → integrations → automation/data flow → proof/ROI → demo.

## 21. EDUCATION / TRAINING

**INDUSTRY SCROLL MODULE**

## 22. Higgsfield Director
**HIGGSFIELD SHOT PACKAGE**
From approved storyboard + real references create coherent website source media. For every shot: chapter; purpose; subject/action;
references; environment; camera/lens intent; framing; lighting; color grade; movement; speed; start frame; end frame; continuity;
duration; aspect ratio; safe text zone; mobile crop; generation prompt; negative constraints. Connected scenes need compatible
end/start compositions. Preserve property/product/person continuity. Do not bake website copy into footage.

## 23. Lovable implementation
**LOVABLE SCROLL ENGINE**
Implement approved storyboard without redesigning it. Create deterministic scroll timelines and map normalized scroll progress to
state. Forward and reverse must work. Use pinning only where specified. Use real-time 3D only with accurate assets; otherwise
scrubbed media/sequence. Keep semantic text/CTA in DOM. Add reduced-motion/mobile fallbacks. Lazy-load below-fold media and
preload only critical hero assets. Do not scroll-jack. Preserve refresh/responsive behavior. Instrument CTA/forms. Before coding
output component map, scroll timeline and asset dependency map.

## 24. QA torture test
**QA / CONVERSION AGENT**
Test: forward slowly/quickly; reverse slowly/quickly; rapid direction changes; stop at arbitrary progress; refresh mid-page;
resize; rotate mobile; touch scroll; reduced-motion; slow network; weak-device fallback. Check factual fidelity, story continuity,
CTA reachability, readability, pin release, loading, layout shift, keyboard/accessibility, overflow and forms. Classify
BLOCKER/HIGH/MEDIUM/POLISH and assign exact fix + owner. Do not approve until reverse-scroll is deterministic.

## 25. Premium gradient/material system
**MATERIAL DIRECTOR**
Build a 3-5 color material palette from brand + imagery: base surface, highlight, shadow, material accent, CTA accent. Gradients
behave like light: radial highlight, edge reflection, atmospheric depth, metallic/stone/glass effect where appropriate. Specify
CSS tokens, angles/stops, contrast and forbidden combinations. Avoid generic rainbow gradients and gradient-everywhere design.
