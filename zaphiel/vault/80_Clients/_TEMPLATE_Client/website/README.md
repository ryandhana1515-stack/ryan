# website/ — output folder of the Website Intelligence & Conversion Strategist

Copy this folder into `80_Clients/<client-slug>/website/` (prospects: `80_Clients/_prospects/<slug>/website/`).
The agent [[10_Agents/05a_Website_Intelligence]] fills the files in this order; the JSON is the hand-off to the Website Builder.

| File | Content |
|---|---|
| 01_research_log.md | every query, URL, date, what was found / not found |
| 02_fact_ledger.md | labelled facts with sources (VERIFIED / CLIENT-PROVIDED / PUBLIC THIRD-PARTY / INFERENCE / UNKNOWN) |
| 03_competitors.md | competitor benchmark (3–5 real competitors) |
| 04_audit_scorecard.md | 20-point score /100 + top 5 fixes |
| 05_strategy.md | real job, CTAs, journey, measurement plan, voice of customer, intent map |
| 06_sitemap_wireframe.md | sitemap + page specs + homepage wireframe |
| 07_copy_draft.md | 5 headline options + homepage copy |
| 08_mockup.html | single-file, mobile-first HTML concept mock-up (CONCEPT banner in PROSPECT mode) |
| 09_questions_for_client.md | open questions / discovery questions for the first call |
| 10_prospect_pitch.md | PROSPECT mode only: 1-page pitch note |
| WEBSITE_BUILD_BRIEF.json | structured hand-off (schema pre-filled) |
