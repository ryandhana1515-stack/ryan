# SEO launch checklist: <client> (titan-seo)

- [ ] Unique title + meta description per page
- [ ] One H1, ordered headings, alt text on every image
- [ ] Canonical URLs; XML sitemap; robots.txt
- [ ] 301 map (if replacing an old site)
- [ ] hreflang (if multi-country/language)
- [ ] Structured data (JSON-LD) only where the content qualifies
- [ ] Open Graph / share cards
- [ ] Core Web Vitals good on mobile (with titan-qa)
- [ ] All copy is real HTML text (not baked into films)
- [ ] Search Console + GA4 + Bing Webmaster set up by the client (access granted)
- [ ] Google Business Profile guidance sent (local businesses)
